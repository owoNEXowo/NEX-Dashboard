# NEX Dashboard 2.6.2

## What's new in 2.6.2

- Reorganized sidebar with optional group separators and grouped personalization settings.
- Adaptive information labels and improved startup card resizing for supported consoles.
- Live CPU, RAM and GPU process metrics, plus a Windows Resource Monitor shortcut.
- Automatic detection of local network adapter type; Ookla consent is remembered across Dashboard updates.
- Separate Windows Update and servicing restart indicators.
- Automated PowerShell 5.1 and 7 syntax, fetch layout and consent persistence tests.

The startup resize behavior depends on the console and PSReadLine version; long or multiline edits are not repainted. Per-process disk and network throughput are not included.

## Что нового в 2.6.2

- Упорядоченное боковое меню с отключаемыми разделителями и группы персонализации.
- Адаптивные подписи и улучшенное изменение размеров стартовых карточек в поддерживаемых терминалах.
- Мониторинг CPU, RAM и GPU по процессам и кнопка открытия монитора ресурсов Windows.
- Автоматическое определение локального сетевого адаптера и сохранение согласия Ookla при обновлении Dashboard.
- Раздельные индикаторы перезапуска Windows Update и системного обслуживания.
- Автоматические тесты синтаксиса, ширины карточек и сохранения согласия в PowerShell 5.1 и 7.

Перерисовка стартовых карточек зависит от терминала и версии PSReadLine; длинные и многострочные команды не перерисовываются. Скорость диска и сети по процессам не предусмотрена.

## Neuerungen in 2.6.2

- Neu geordnetes Seitenmenü mit optionalen Trennlinien und gruppierten Personalisierungseinstellungen.
- Adaptive Beschriftungen und verbesserte Größenanpassung der Startkarten in unterstützten Konsolen.
- CPU-, RAM- und GPU-Metriken pro Prozess sowie eine Verknüpfung zum Windows-Ressourcenmonitor.
- Automatische Erkennung des lokalen Netzwerkadapters; Ookla-Zustimmung bleibt bei Dashboard-Updates erhalten.
- Getrennte Neustartanzeigen für Windows Update und Wartung.
- Automatische Syntax-, Layout- und Zustimmungstests für PowerShell 5.1 und 7.

Die Größenanpassung hängt von der Konsole und der PSReadLine-Version ab; lange oder mehrzeilige Eingaben werden nicht neu gezeichnet. Datenträger- und Netzwerkraten pro Prozess sind nicht enthalten.

## Installation / Установка / Installation

- New installation / Новая установка / Neuinstallation: `NexDashboard-2.6.2-EasyInstall.zip` — extract, then run `Install.cmd`.
- Existing users / Обновление / Update: Dashboard Update Center or `NexDashboard-2.6.2-Public.ps1`.
- `SHA256SUMS.txt`: SHA-256 checksums for both downloads.

Windows 11 / Windows PowerShell 5.1 is the primary target. PowerShell 7 automated checks cover syntax, layout and consent persistence, not all interactive features. The maintainer has tested the final source on their Windows PC; compatibility across every PC is not guaranteed. MIT-licensed source; third-party components keep their own licenses.
