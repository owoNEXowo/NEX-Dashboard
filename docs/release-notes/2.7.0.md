# NEX Dashboard 2.7.0

## What's new in 2.7.0

- **Built-in Terminal Editor:** Tabs, syntax colors, search with match navigation, mouse selection, clipboard, undo/redo, auto-pairs, auto-indent, local inline completion, matching brackets and zoom/reset.
- **File Explorer:** Clickable breadcrumbs, extension-preserving rename with live preview, optional Windows “Open with” registration and the NEX icon.
- **Benchmarks and storage:** Time-limited CPU, RAM and GPU workloads with selectable memory budgets and reports; read-only search for large files and folders.
- **Personalization and monitoring:** Theme-derived light mode, favorites (F6), adaptive sidebar, compact layout, home blocks, draggable monitor cards, smoother indicators and new status widgets.
- **Diagnostics and updates:** Read-only full PC scan, backed-up settings reset, F8 privilege switch through a replacement Terminal window, background release check and animated update feedback.

Benchmarks are not a complete stability test. Available sensors and safe memory budgets depend on the hardware and drivers. Code completion is dictionary-based, not a full language server. Zoom and elevation depend on Windows Terminal; F8 uses Windows UAC and replaces the session, so save work first.

## Что нового в 2.7.0

- **Встроенный редактор:** Вкладки, подсветка синтаксиса, поиск с переходом между совпадениями, выделение мышью, буфер обмена, отмена и повтор, автоскобки, отступы, локальное автодополнение, подсветка парных скобок и масштаб со сбросом.
- **Проводник:** Кликабельные сегменты пути, сохранение расширения при переименовании с предпросмотром, опциональная регистрация в «Открыть с помощью» и иконка NEX.
- **Бенчмарки и накопители:** Ограниченные по времени тесты CPU, RAM и GPU, выбор объёма памяти, отчёты и поиск крупных файлов и папок без изменения данных.
- **Персонализация и мониторинг:** Светлый режим на основе темы, избранное (F6), адаптивное меню, компактный режим, блоки главной страницы, перетаскивание карточек, плавные индикаторы и новые виджеты.
- **Диагностика и обновления:** Полная диагностика ПК без автоматического ремонта, сброс с резервной копией, переключение прав F8 через замену окна Terminal, фоновая проверка релизов и анимированные индикаторы.

Бенчмарки не заменяют полноценную проверку стабильности. Доступность датчиков и безопасный объём памяти зависят от железа и драйверов. Автодополнение основано на словарях, это не полноценный языковой сервер. Масштаб и переключение прав зависят от Windows Terminal; F8 использует UAC и заменяет сеанс, поэтому сначала сохраните работу.

## Neuerungen in 2.7.0

- **Integrierter Terminal-Editor:** Tabs, Syntaxfarben, Suche mit Treffernavigation, Mausauswahl, Zwischenablage, Rückgängig/Wiederholen, automatische Klammerpaare und Einrückung, lokale Inline-Vervollständigung, Klammerhervorhebung und Zoom/Reset.
- **Dateimanager:** Anklickbare Pfadsegmente, Umbenennung mit Dateiendung und Live-Vorschau sowie optionale Registrierung unter „Öffnen mit“ mit NEX-Symbol.
- **Benchmarks und Laufwerke:** Zeitbegrenzte CPU-, RAM- und GPU-Tests mit wählbarem Speicherbudget und Berichten; schreibgeschützte Suche nach großen Dateien und Ordnern.
- **Personalisierung und Monitoring:** Designbasierter Hellmodus, Favoriten (F6), adaptive Seitenleiste, Kompaktlayout, Startblöcke, verschiebbare Monitorkarten, sanftere Anzeigen und neue Status-Widgets.
- **Diagnose und Updates:** Schreibgeschützte PC-Diagnose, Einstellungsreset mit Sicherung, F8-Berechtigungswechsel über ein Ersatz-Terminalfenster, Hintergrundprüfung und animierte Update-Anzeigen.

Benchmarks ersetzen keinen vollständigen Stabilitätstest. Sensoren und sichere Speicherbudgets hängen von Hardware und Treibern ab. Die Vervollständigung basiert auf Wörterbüchern, nicht auf einem vollständigen Sprachserver. Zoom und Berechtigungswechsel hängen von Windows Terminal ab; F8 nutzt UAC und ersetzt die Sitzung, daher vorher speichern.

## Installation / Установка / Installation

- **EN:** Extract `NexDashboard-2.7.0-EasyInstall.zip` and run `Install.cmd`. Existing users can update through the NEX Update Center or select the public PS1 locally.
- **RU:** Распакуйте `NexDashboard-2.7.0-EasyInstall.zip` и запустите `Install.cmd`. Для обновления используйте центр обновлений NEX или выберите публичный PS1 локально.
- **DE:** `NexDashboard-2.7.0-EasyInstall.zip` entpacken und `Install.cmd` starten. Bestehende Installationen über das NEX Update-Center oder die öffentliche PS1-Datei aktualisieren.

`SHA256SUMS.txt` contains the SHA-256 hashes of both downloadable assets. Only run files from a trusted source. Windows 11 / Windows PowerShell 5.1 is the primary target.
