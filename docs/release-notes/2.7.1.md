# NEX Dashboard 2.7.1

## English
- Update Center shows the actual installer download size before confirmation, live transferred bytes and percentage, and separate SHA-256 verification status.
- Existing release integrity checks and explicit installation confirmation remain in place.

## Русский
- Центр обновлений показывает размер установщика до подтверждения, фактический прогресс загрузки в байтах и процентах, отдельный статус проверки SHA-256.
- Проверка целостности и подтверждение установки сохранены.

## Deutsch
- Das Update-Center zeigt die Downloadgröße vor der Bestätigung, den tatsächlichen Fortschritt in Bytes und Prozent sowie einen separaten SHA-256-Prüfstatus.
- Integritätsprüfung und ausdrückliche Installationsbestätigung bleiben erhalten.

## Installation / Установка / Installation
Extract `NexDashboard-2.7.1-EasyInstall.zip` and run `Install.cmd`, or update using NEX Update Center. The new progress display applies to downloads initiated from 2.7.1 onward.
