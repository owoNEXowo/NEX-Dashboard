# NEX Dashboard 2.7.2

## Support and feedback

Need help? Open **F1 → Support and feedback** or find it using Ctrl+K. You can also use the NEX Update Center. GitHub opens in your browser; no reports or personal data are sent automatically.

## Поддержка и отзывы

Откройте **F1 → Поддержка и отзывы** или найдите этот пункт через Ctrl+K. Он также доступен в центре обновлений NEX. GitHub открывается в браузере; данные автоматически не отправляются.

## Hilfe und Feedback

Öffnen Sie **F1 → Hilfe und Feedback** oder suchen Sie mit Ctrl+K. Die Funktion ist auch im NEX Update-Center verfügbar. GitHub öffnet sich im Browser; Daten werden nicht automatisch gesendet.

[GitHub Issues](https://github.com/owoNEXowo/NEX-Dashboard/issues)

Installation: extract NexDashboard-2.7.2-EasyInstall.zip and run Install.cmd, or update through NEX Update Center. SHA256SUMS.txt contains the release file hashes.
